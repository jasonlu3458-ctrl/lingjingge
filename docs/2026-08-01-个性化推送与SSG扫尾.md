## 1. Dify 应用配置（DailyZenPusher）

### 1.1 在 Dify 后台新建应用
- 应用类型：**Chatflow** 或 **Workflow** 均可（推荐 Workflow，便于控变量）
- 名称：`DailyZenPusher`
- 模型：选便宜稳定的（如 `gpt-4o-mini` / `qwen-turbo` / `deepseek-chat`）
- API Key 复制后填到 `.env.local` 与 Vercel：
  ```
  DIFY_PUSH_API_KEY=app-xxxxxxxxxxxxxxxx
  ```

### 1.2 系统提示词（粘到 Dify 的 System Prompt 框）

```
你是「灵境尊者·阿阇梨」，一位年长、温和、富有禅机的引路人。
你的任务是根据同修的命理画像和近期活跃度，为 TA 生成一句
20-40 字的「今日禅机」推送文案。

# 严格输出格式
- 必须以「同修，」开头（这是约定招呼语）。
- 不使用任何 emoji、链接、Markdown。
- 不使用超过 1 个感叹号。
- 一句话即可，不要分段、不要解释。

# 关怀语气
- 像一位老朋友在清晨为你端上一杯茶。
- 不要说教、不要堆砌佛学术语。
- 不要引用具体经文名（除非变量里给出）。

# 输入变量
- {{user_traits}}：JSON，例如
  {"element":"木","dayStem":"甲","deity":"青龙","summary":"木日主·张三"}
- {{days_inactive}}：数字，最后一次活跃距今天数。

# 写作要点（结合五行）
- 木日主：鼓励舒展、生长、踏出舒适圈。
- 火日主：提醒静心、避燥、晚间少用眼。
- 土日主：安慰稳健、勿急、守住节奏。
- 金日主：提示决断、收敛锋芒、修边界。
- 水日主：慰藉流动、顺势、不必强求。
- {{days_inactive}} > 3：语气更温柔，唤回而非催促。
```

### 1.3 变量注入
- 在 Dify 工作流的「开始」节点添加两个输入变量：
  - `user_traits` (String)
  - `days_inactive` (String)
- 提示词里用 `{{user_traits}}` / `{{days_inactive}}` 引用。

### 1.4 测试
- 用「调试与预览」输入：
  - `user_traits = {"element":"木","dayStem":"甲"}`
  - `days_inactive = 0`
- 应得到一句 20-40 字的「同修，……」文案。
- 模型平均响应应 < 4s；若 > 4s，提示词已自动降级（见 ai-push-utils.ts）。

### 1.5 Vercel 环境变量
到 Vercel → Project Settings → Environment Variables：
```
DIFY_PUSH_API_KEY=app-xxxxxxxxxxxx
DIFY_BASE_URL=https://api.dify.ai/v1
```
（BASE_URL 也可填自建 Dify 地址；ai-push-utils.ts 已读取。）

## 2. web-push VAPID 配置

### 2.1 安装依赖
```bash
npm install web-push
```
package.json 已添加 `web-push`。`send-daily-zen` 路由会通过
`src/lib/web-push-helper.ts` 自动调用。

### 2.2 生成 VAPID 密钥
在项目根目录执行：
```bash
npx web-push generate-vapid-keys
```
会输出两行：
```
Public Key:  BAbc...
Private Key: xyz...
```

### 2.3 写入环境变量
`.env.local`：
```
WEB_PUSH_VAPID_PUBLIC_KEY=BAbc...
WEB_PUSH_VAPID_PRIVATE_KEY=xyz...
WEB_PUSH_VAPID_SUBJECT=mailto:admin@lingjingge.com
# 暴露公钥给浏览器（订阅时需要）
NEXT_PUBLIC_WEB_PUSH_VAPID_PUBLIC_KEY=BAbc...
```

Vercel 同步添加（**不**勾 Public，因为私钥绝不能暴露）：
- `WEB_PUSH_VAPID_PUBLIC_KEY`
- `WEB_PUSH_VAPID_PRIVATE_KEY`
- `WEB_PUSH_VAPID_SUBJECT`
- `NEXT_PUBLIC_WEB_PUSH_VAPID_PUBLIC_KEY`

### 2.4 客户端订阅
未来在 `/muxintang/me` 加订阅按钮：
```js
const reg = await navigator.serviceWorker.register('/sw.js');
const sub = await reg.pushManager.subscribe({
  userVisibleOnly: true,
  applicationServerKey: process.env.NEXT_PUBLIC_WEB_PUSH_VAPID_PUBLIC_KEY,
});
await fetch('/api/me/push-subscribe', { method: 'POST', body: JSON.stringify(sub) });
```

## 3. Supabase 迁移

打开 Supabase 控制台 → SQL Editor → New query，粘贴并执行：
`supabase/migrations/20260801_personalized_push.sql` 中的内容。

执行后：
- `profiles` / `user_profiles` 表会新增 4 列。
- 已有 RLS 策略自动覆盖（无需新增）。
- 单列索引（`is_push_enabled` / `last_zen_sent_at`）会加速 cron 扫描。
